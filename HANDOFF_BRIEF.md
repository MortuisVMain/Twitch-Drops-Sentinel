### 🧭 Схема навигации между экранами (Navigation System)
Навигация управляется через состояние `activeTab: NavTab` в `src/App.tsx`:
- `'dashboard'` — **Дашборд** (мониторинг стрима, активный дроп, прогресс-бар, таймеры, Hardware Guard, лог).
- `'shelf'` — **Полка игр** (список установленных игр, каталог кампаний с дропами, приоритеты, фильтр «🏆 Собрано»).
- `'giveaways'` — **Раздачи** (хаб 7 игровых магазинов: Epic, GOG, Steam, Prime, Fab, Unity, Itch, авто-клейм, статус планировщика).
- `'settings'` — **Настройки** (автовыключение ПК, пауза при играх, пути сканирования, сброс аккаунта, проверка апдейтов).
- `'dimmer'` — **Диммер экранов** (аппаратный контроль подсветки мониторов DDC/CI, блэкаут, таймер сна).

Переключение реализовано через плавающий оптический док (**Floating Glass Dock**) в нижней части экрана с индикацией активной вкладки, бейджами статуса и тактильным звуковым кликом.

Каждый экран обернут в `TabErrorBoundary` — если внутри сложного компонента возникнет ошибка рендеринга, приложение не упадет в белый экран, а покажет аккуратную карточку восстановления с кнопкой «Вернуться в Дашборд».

- **Углубленные пазы (`--bg-recessed`):** `#050608` — для полос прогресса и консольных логов.

### 🌿 Благородная мята (Noble Mint — функциональный акцент):

## ⚠️ 4. Hard Constraints (Что категорически нельзя ломать)

При переработке верстки и компонентов необходимо сохранить неизменными следующие архитектурные узлы:

1. **Twitch Device OAuth Flow (Без полей логина и пароля):**
   - Бэкенд **никогда** не принимает логин и пароль пользователя! Авторизация идет через протокол устройств.
   - Если `cookies.jar` отсутствует, в стейте приходят `oauth_code` (например, `ABCD-1234`) и `oauth_uri`. UI должен отобразить этот код с кнопкой «Скопировать» и ссылкой `https://www.twitch.tv/activate`.
   - Кнопка выхода из аккаунта вызывает `POST /api/auth/logout`, который стирает cookies на диске.

2. **Двухконтурная модель таймера дропа (Zero-Lag Countdown):**
   - Запрос к бэкенду `/api/state` выполняется раз в 3 секунды.
   - Однако локальный счетчик секунд (`remaining_seconds`) в хуке `useSentinelState.ts` уменьшается **каждую 1 секунду** (`setInterval(..., 1000)`). Не заменяйте это на опрос сервера каждую секунду — это перегрузит Python-сервис и вызовет фризы на слабых ПК.

3. **Интеграция с Планировщиком задач Windows (`Task Scheduler`):**
   - Автоматический сбор раздач завязан на задачу `FreeGamesClaimerStudio` в Планировщике Windows.
   - Управление тумблером «Автосбор раздач по расписанию» должно строго дергать `POST /api/v1/giveaways/toggle-scheduler`. Не удаляйте отображение статусов `Ready` / `Running` / `Disabled`.

4. **Оптимистичные обновления (Optimistic UI):**
   - При клике по звездочке «Приоритет игры» или исключению игры UI обязан изменить состояние карточки мгновенно, не дожидаясь ответа сервера, а сетевой запрос отправить в фоне.

5. **Безопасность окна и трея:**
   - C# хост (`desktop/MainForm.cs`) обеспечивает сворачивание в трей при клике на крестик, восстановление по клику на иконку в трее и темную DWM-рамку. Фронтенд должен иметь фиксированную ширину контента и не допускать появления горизонтального скроллбара (`overflow-x: hidden`).

## 🚀 5. Phase 1 Starter Pack (С чего начать первый этап редизайна)

Для быстрого старта внешнему специалисту рекомендуется следующая последовательность:

### Шаг 1: Запуск локального мок-сервера и среды разработки
В комплекте подготовлен автономный скрипт `main.py`, который эмулирует все эндпоинты бэкенда с реалистичными данными:
```bash
# Терминал 1: запуск мок-сервера API
python main.py

# Терминал 2: запуск фронтенда
npm install
npm run dev
```
Браузер откроется на `http://localhost:5173/`, подключится к мок-серверу на порту `28492` и покажет все экраны с рабочими данными.

### Шаг 2: Три ключевых файла для первой итерации:
1. **`src/index.css` (или `DESIGN.md`)**:
   - Настройте базовые CSS-переменные, цвета шасси, градиенты карточек и типографику.
2. **`src/App.tsx`**:
   - Освежите компоновку верхнего статус-бара (шапка профиля Twitch, бейджи статуса) и нижнего плавающего дока навигации.
3. **`src/components/LiveDashboard.tsx`**:
   - Базовый флагманский экран! Переработайте карточку активного дропа (большая обложка игры, тактильный прогресс-бар с мятным свечением, таймер обратного отсчета) и виджеты телеметрии оборудования (Hardware Guard). После утверждения Дашборда визуальный язык легко переносится на остальные вкладки («Полка игр», «Раздачи», «Настройки»).

Разделы 3 и 5 выше описывают тему Apple Luna 2.0 и сохранены как история. Актуальный UI называется **Sentinel Field-Deck** (Flat-2D). Эталон токенов: `src/index.css` (`[data-theme]`: titanium по умолчанию, luna-mint, gradient, cyberpunk, light, copper, apple-luna). Подробности: приложение в конце `DESIGN.md` и `docs/solutions/052-v3.3.5-field-deck-audit.md`.

Дополнение к Hard Constraints:
- `test_sentinel_suite.py` бьёт в боевой порт 28492 и вызывает `/api/installed-games/clear` и `/api/trophies/clear`. Теперь тест сам сохраняет и возвращает `data/installed_games.json` и `Trophies.md`, но всё равно запускать только при закрытом приложении.
- Запуск с portable Python: `portable_runtime\python\python.exe -c "import sys,runpy; sys.path.insert(0,'.'); runpy.run_path('test_sentinel_suite.py', run_name='__main__')"` (у embeddable Python файл `._pth` не добавляет папку скрипта в `sys.path`).

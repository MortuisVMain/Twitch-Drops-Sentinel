# Решение 050: Удаление избыточной панели сенсоров телеметрии с Дашборда

## Контекст и проблема
На вкладке «Дашборд» под 40-сегментной светодиодной шкалой прогресса отображалась горизонтальная полоса аппаратных сенсоров `guard-sensors-4`:
- GPU НАГРУЗКА: 0.0% (STREAMLESS)
- CPU ДЕМОНА: 1.2% (22 MB)
- ОЦЕНКА ЭКОНОМИИ ТРАФИКА: 0.1 GB
- СКОРОСТЬ / PING: DIRECT • 18 MS

Пользователь указал, что блок не несёт полезной ценности («ниче толкового не показывает») и визуально захламляет рабочее пространство над Живой консолью операций.

## Решение
1. **LiveDashboard.tsx**:
   - Хирургически удалена разметка блока `<div className="guard-sensors-4">...</div>`.
   - Живая консоль операций (`middle-console-island`) получила дополнительное вертикальное пространство.
2. **Синхронизация тестов**:
   - Обновлены тесты `test_dashboard_deep.py` и `test_dashboard_full_operational.py` (замена проверки наличия удалённых строк на `assertNotIn("guard-sensors-4")`).
   - Успешный прогон генерального набора верификаций `test_sentinel_suite.py` (36 из 36 гейтов `Exit Code 0`).
3. **Сборка фронтенда**:
   - Пересобран чистый единый бандл `dist/index.html` (594 KB).

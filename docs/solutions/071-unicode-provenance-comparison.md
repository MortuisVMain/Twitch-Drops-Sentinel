# Сопоставление Unicode-путей при проверке происхождения

Дата: 2026-11-06.

Контекст: [карта происхождения ядра Twitch-фарма](../Twitch%20Farming%20Core%20Provenance%20Map.md).

При сравнении переводов с TwitchDropsMiner первоначальная проверка ошибочно отнесла `Українська.json` к отсутствующим в исходном проекте. Повторная проверка дерева и содержимого Git подтвердила наличие файла. Отображение или экранирование Unicode-пути нельзя использовать как доказательство отсутствия исходника.

Надёжная последовательность:

1. Получить дерево фиксированного коммита через `git -c core.quotepath=false ls-tree -r --name-only` и декодировать вывод как UTF-8.
2. Сравнить имена как Unicode-строки.
3. Для сравнения содержимого использовать идентификаторы blob и `git cat-file blob`, исключая повторную интерпретацию Unicode-пути оболочкой.
4. Явно различать побайтовое совпадение и совпадение после нормализации переводов строк.

Проверенный результат для TwitchDropsMiner `99d12fd2d815d7737258ed57405c63c0686bd3e1`: 20 исходных и 21 локальный JSON-файл переводов; все 20 исходных имён найдены локально; только `English.json` не имеет одноимённого исходного файла. После нормализации `Čeština.json` совпадает, 19 остальных общих файлов отличаются. Команды повторной проверки завершились с кодом 0.

Эти результаты устанавливают сходство и различие конкретных файлов, а не независимое авторство изменённых строк.

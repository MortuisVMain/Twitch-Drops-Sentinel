# Solution 024: Twitch Drops Progress Stall Resolution (Full HLS Chunk HEAD Cadence & 20s Loop)

## Проблема
Пользователь столкнулся с полным отсутствием начисления прогресса дропов: за полтора часа на дропе начислялось всего 1-2 минуты (3%), стримеры постоянно ротировались каждые 2-15 минут, а игры уходили в 30-минутный кулдаун. При этом прямые Spade POST возвращали статус `204 No Content`.

## Коренная причина (Root Cause)
1. **Кастрация метода симуляции HLS в `core/channel.py`:**
   В Sentinel v3 метод `send_watch()` был переписан так, что слал HEAD-запрос только к **одному последнему чанку** (`chunk_lines[-1]`) m3u8-плейлиста, полагаясь на Spade POST. Один чанк равен ~2 секундам видео. CDN Twitch видел, что плеер запрашивает лишь 2 секунды видео в минуту, считал стрим зависшим/приостановленным и не передавал события просмотра в Drops Worker.
2. **Искажение `WATCH_INTERVAL` в `core/constants.py`:**
   Интервал был завышен с канонических **20 секунд** до **59 секунд**, из-за чего запросы к CDN шли в 3 раза реже минимального буфера воспроизведения.
3. **Бесполезность Spade POST при токенах SMARTBOX (`ue6666...`):**
   Spade принимает сырой JSON на шлюзе Kafka со статусом 204, но воркер дропов отбрасывает его без параллельного подтверждения загрузки видеопотока из CDN.
4. **Несовместимость pickle Morsel cookie между Python 3.14 и Python 3.12:**
   Python 3.14 добавляет атрибут `partitioned`, который при загрузке в Python 3.12 (portable_runtime) вызывал `CookieError: Invalid attribute 'partitioned'`, сбрасывая сессию.

## Внедренное решение (Surgical Fix)
1. **Восстановлен полный HLS-цикл в `core/channel.py`:**
   `send_watch()` отправляет HEAD-запросы ко **всем 15 чанкам** m3u8-плейлиста стрима (`chunk.startswith("http")`), полностью эмулируя непрерывный поток воспроизведения.
2. **Возвращен канонический `WATCH_INTERVAL = timedelta(seconds=20)` в `core/constants.py`.**
3. **Синхронизирован `_watch_loop` в `core/twitch.py`:**
   Каждые 20 секунд шлется пачка чанков, а каждые 3 тика (~60 секунд) опрашивается GQL `CurrentDrop` с привязкой сессии и обновлением GUI.
4. **Добавлен патч совместимости `http.cookies.Morsel._reserved['partitioned'] = 'Partitioned'` для Python 3.12.**

## Результаты верификации
1. **HITMAN World of Assassination** (`ethenpov` / `BurtonTTV`):
   Прогресс дропа *Purple Streak Crowbar* вырос с **16 мин → 17 → 18 → 19 → 20 мин** (33%) в режиме реального времени.
2. **AION 2** (`fubgun`):
   Прогресс дропа *Head Bow* вырос с **203 мин → 204 мин** ровно за 2 минуты.
3. Полный сьют `test_sentinel_suite.py` — **15/15 тестов пройдены с Exit Code 0**.

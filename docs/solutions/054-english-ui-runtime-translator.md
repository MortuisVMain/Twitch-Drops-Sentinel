# 054. Английский интерфейс: рантайм-переводчик по русскому тексту

**Задача.** UI был только русским (~980 русских строк в `src/`); `core/lang/*.json` переводил лишь консоль ядра.

**Решение.** `src/i18n/`: русский остаётся исходным языком в компонентах, в английском режиме `installTranslator()` переписывает текстовые узлы и атрибуты `title`/`placeholder`/`aria-label`/`alt` по словарю `en/*.ts` (ключ — русский текст) и по шаблонам `patterns.ts` (динамические строки: `$1`-подстановки или функции для множественного числа). Захваченные группы переводятся рекурсивно, составные строки делятся по ` · `, ` • `, ` — `, `, `. `MutationObserver` держит перевод при перерисовках React. `alert/prompt/confirm` и `document.title` переводятся отдельно. Даты берут локаль из `uiLocale()`.

**Почему не `t('ключ')` в каждом компоненте.** ~700 мест правки логики дали бы риск регрессий без UI-тестов, а русский текст пришлось бы переносить в словарь. Рантайм-слой не меняет ни одной строки компонентов; цена: перевод идёт по готовому тексту, поэтому словарь привязан к точной русской формулировке.

**Язык.** `localStorage.sentinel_ui_lang` (ru|en); переключатель в Настройках пишет `language` («Русский»/«English») в `config.json` через `/api/settings`, сервис вызывает `apply_engine_language()` (консоль ядра следует тому же языку) и UI перезагружается, чтобы пересобрать подписи уровня модуля. Если `config.json` говорит English/Русский, а UI другой, UI один раз следует за конфигом. Остальные значения `language` (Deutsch и т.д.) UI игнорирует.

**Защита от дыр.** `tools/check_i18n.mjs` (AST TypeScript + реальный `translate()`) падает на любой русской строке без перевода; для шаблонов проверяется образец вывода. Гейт `test_english_ui_covers_every_russian_string` в `test_sentinel_suite.py`. Правило для нового текста: добавить русскую строку в компонент **и** её перевод в `src/i18n/en/*.ts` (или шаблон в `patterns.ts`).

**Ограничения.** Тексты оболочки `MainForm.cs` (диалог закрытия, трей) и сообщения бэкенда, которых нет в `core/lang`, остаются русскими; строки `console.*` не переводятся (для разработчика). Словарь привязан к русскому тексту: правка русской формулировки без правки словаря вернёт русский в английском режиме (поймает проверка).

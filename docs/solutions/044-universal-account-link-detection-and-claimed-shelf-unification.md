# Решение gotcha: Универсальное определение привязки аккаунтов (4-Way Link Detection) и унификация полки «Собрано»

## Симптом
1. Вкладка `🏆 Собрано (0)` на Полке Игр отображалась пустой (хотя у пользователя в инвентаре Twitch уже получено более 160 наград по 19 играм).
2. Рядом находилась избыточная кнопка фильтра `🏆 Витрина 3D Трофеев (42)`, дублирующая смысл собранных наград.
3. Игра *Hunt: Showdown 1896* (а также ряд других игр: Rust, Cyberpunk 2077, Delta Force) отображалась со статусом `⚠️ Нужна привязка`, несмотря на то, что аккаунт пользователя привязан и награды успешно забираются.
4. Бейдж привязки наползал на край картриджа из-за отсутствия адаптивного отступа.

## Первопричина (Root Cause)
1. **Специфика Twitch Drops API (Issue #56 Twitch Drops Miner):** Twitch GQL `ViewerDropsDashboard` возвращает `isAccountConnected: true` исключительно для игр с нативным Twitch OAuth. Игры с внешней связкой через сайты разработчиков (`huntshowdown.com/twitchdrops`, `cyberpunk.net`, `crossout.net`) передают `accountLinkURL`, из-за чего эвристика классифицировала их как непривязанные (`is_connected = not bool(link_url)`).
2. **Изоляция источника данных собранного:** `GameShelf.tsx` фильтровал игры во вкладке `claimed` исключительно по локальному парсеру Markdown-файла `Trophies.md` (`claimedTrophiesByGame`), игнорируя реальные поля инвентаря `claimed_drops > 0` и `is_finished === true` в каталоге игр.
3. **Дублирование фильтров:** Кнопки «Собрано» и «Витрина 3D Трофеев» делили одно и то же смысловое пространство.

## Решение

### 1. Универсальный 4-сторонний детектор привязки (Universal 4-Way Link Detection)
В `core/sentinel_service.py` и `GameShelf.tsx` внедрена автоматическая верификация:
- **Условие 1 (Twitch OAuth):** Нативный флаг `linked == True`.
- **Условие 2 (Twitch Inventory Proof):** `claimed_drops > 0` (пользователь математически доказал привязку, забрав хотя бы один дроп).
- **Условие 3 (Кампания завершена):** `is_finished == True` (все дропы собраны).
- **Условие 4 (Ручной реестр & Trophies.md):** Игра есть в постоянном списке `settings.user_linked_games` или в `Trophies.md`.

### 2. Новые API и интерактивный бейдж
- Добавлен REST-эндпоинт `POST /api/games/toggle-linked` с сохранением в `settings.json`.
- В хуке `useSentinelState` добавлен метод `handleToggleUserLinked(gameName)`.
- На карточке игры:
  - Если привязана: компактный изумрудный бейдж `✓ Привязан` (`top: 6px, right: 6px`, шрифт 8px).
  - Если не привязана: ссылка `⚠️ Нужна привязка` (открывает сайт разработчика) + кнопка `[✓]` (*"Отметить как привязанный"* в 1 клик).

### 3. Унификация полки собранного
- Из верхней панели фильтров удалена дублирующая кнопка `🏆 Витрина 3D Трофеев`, оставлена единая вкладка `🏆 Собрано ({claimedCount})`.
- Во вкладке `🏆 Собрано` теперь отображаются все 19 игр с полученными дропами или завершенными кампаниями.
- Внутри вкладки встроен сворачиваемый блок 3D-витрины `#holoTrophyVault` с кнопками `▲ Свернуть 3D / ▼ 🏆 Витрина 3D Трофеев` и `📄 Открыть Trophies.md`.

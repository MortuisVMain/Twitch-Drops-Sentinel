# Решение 028: Ликвидация ложных пауз Hardware Guard и 1-клик очистка кэша игр

## Проблема
1. **Ложные срабатывания Hardware Guard:** При запуске пользователем обычных программ или фоновых утилит (например, `Happ.exe`, `mscopilot.exe`, `Spotify.exe`) приложение ставило сбор дропов на паузу, заявляя, что запущена игра.
   - *Коренная причина:* В фоновом цикле `games_folder_rescan_loop` ранее производилась слепая инъекция всех найденных в реестре деинсталляции Windows `.exe` в список `games_to_pause`. Из-за этого реестровые утилиты автоматически попадали в список блокировок.
2. **Тревожный дублирующий UI:** Вверху окна появлялся яркий оранжевый баннер с сообщением об обнаружении процесса, который дублировался аналогичной карточкой в дашборде. При этом у пользователя не было возможности быстро сказать программе: «Это не игра, продолжай сбор».
3. **Отсутствие сброса установленных игр:** При необходимости пересканировать или очистить список ошибочно распознанных игр не было кнопки сброса кэша `installed_games.json`.

## Решение (Архитектура Apple Luna 2.0 & Karpathy)
1. **Изоляция списка отслеживаемых игр (`core/sentinel_service.py`):**
   - Полностью исключена мутация `games_to_pause` из сканера игр. Список игр для паузы зафиксирован только для доверенных AAA-тайтлов (`DEFAULT_GAMES_PROCESSES`).
   - Добавлен глобальный сет `SYSTEM_NON_GAME_EXES` (более 40 системных процессов, включая `happ.exe`, `mscopilot.exe`, `spotify.exe`, `telegram.exe`, браузеры, лаунчеры и апдейтеры).
   - Внедрена автоматическая миграция: если у пользователя в `config.json` накопилось >60 мусорных процессов, список автоматически сбрасывается к эталонному дефолту.
   - Добавлена поддержка постоянного списка исключений `ignored_processes`.
2. **REST API игнорирования процесса и сброса кэша:**
   - `POST /api/hardware/ignore-process`: удаляет имя процесса из `games_to_pause`, заносит его в `ignored_processes`, снимает паузу с клиента и мгновенно возобновляет фарм без перезапуска приложения.
   - `POST /api/installed-games/clear`: очищает `data/installed_games.json`, пересобирает каталог и оповещает клиентов через WebSocket.
3. **Лаконичный UI в стиле Apple Luna 2.0:**
   - Из `App.tsx` удален дублирующий оранжевый баннер из шапки.
   - В `LiveDashboard.tsx` карточка Hardware Guard переработана в спокойный блок со статусным бейджем и кнопками `[✕ Это не игра (Игнорировать)]` и `[▶ Продолжить сбор]`.
   - В `GameShelf.tsx` и `SettingsStudio.tsx` добавлена кнопка `[🗑️ Очистить список]`.
4. **Защита сборщика релизов (`tools/create_clean_release.py`):**
   - Добавлена строгая фильтрация `*.log` файлов и `settings.json` из сборки релизов, гарантирующая размер хот-патча ~370 KB вместо 18 MB.

## Верификация
- Гейт 25 тестового набора подтвердил: процесс `happ.exe` игнорируется, эндпоинты `/api/hardware/ignore-process` и `/api/installed-games/clear` отрабатывают штатно.
- Все 25 гейтов `test_sentinel_suite.py` пройдены с Exit Code 0.
- Релиз `v3.1.2` с чистыми архивами (без логов и куки) опубликован на GitHub Releases.

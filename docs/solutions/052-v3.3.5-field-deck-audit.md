# 052 — Аудит v3.3.5 Field-Deck: деструктивный набор тестов, молчаливые ошибки, терминология

**Дата:** 2026-11-01. **Ветка:** `audit/v3.3.5` (локально, без push).

## Нетривиальные находки

1. **Набор тестов стирал данные пользователя (P0 для данных).** Гейты 25 и 28 вызывают на боевом порту `28492` эндпоинты `/api/installed-games/clear` и `/api/trophies/clear`. После прогона `data/installed_games.json` стал 2 байта (было 60100), `Trophies.md` потерял журнал. Исправление: тест сохраняет оба файла в `finally` и возвращает их; демон, который поднимает набор, теперь гасится через `atexit`, даже если гейт упал. Файлы восстановлены из `backups/pre-audit-3.3.5-*.zip`.
2. **Embeddable Python и `sys.path`.** У `portable_runtime/python` файл `python312._pth` отключает автодобавление папки скрипта, поэтому `from core.game_scanner import ...` падает (`ModuleNotFoundError`). Запуск через `runpy` с `sys.path.insert(0, '.')`. Флаг `-I` для набора использовать нельзя.
3. **Версия при ошибке проверки обновлений.** `handle_check_updates` брал `getattr(UPDATER, "current_version", "3.3.4")`, но такого атрибута нет, поэтому при сбое сети UI показывал 3.3.4. Теперь берётся `version.__version__`.
4. **Молчаливые ошибки.** Реальная картина: в `core` 27 пустых `pass`/`suppress` (почти все best-effort), во фронте и в `MainForm.cs` дефектными были сетевые обработчики полки/раздач/настроек и возврат звука после блэкаута. Исправлены с логированием (`console.error`, `desktop_errors.log`). Dispose/Unregister оставлены best-effort осознанно.
5. **Терминология.** «Раздачи» относятся только к вкладке бесплатных игр; для Twitch Drops используются «дропы / кампании».
6. **Вёрстка.** `.engraved-header .tag` не переносится; шапка планировщика Раздач переносит кнопки на 1280×720.

## Не дефекты (проверено)

- Все 47 URL фронта существуют в `sentinel_service.py`.

# 052 — Аудит v3.3.5 Field-Deck: деструктивный набор тестов, молчаливые ошибки, терминология

**Дата:** 2026-11-01. **Ветка:** `audit/v3.3.5` (локально, без push).

## Нетривиальные находки

1. **Набор тестов стирал данные пользователя (P0 для данных).** Гейты 25 и 28 вызывают на боевом порту `28492` эндпоинты `/api/installed-games/clear` и `/api/trophies/clear`. После прогона `data/installed_games.json` стал 2 байта (было 60100), `Trophies.md` потерял журнал. Исправление: набор работает в песочнице (временная копия кода и данных, свой сервис на свободном порту, `SENTINEL_SERVICE_PORT` / `SENTINEL_TEST_MODE=1`), в конце сверяет sha256 боевых файлов; демон гасится через `atexit`. Доказано пробником на порту 28492: 0 соединений за прогон. Файлы восстановлены из `backups/pre-audit-3.3.5-*.zip`.
2. **Embeddable Python и `sys.path`.** У `portable_runtime/python` файл `python312._pth` отключает автодобавление папки скрипта, поэтому `from core.game_scanner import ...` падает (`ModuleNotFoundError`). Теперь набор сам добавляет корень песочницы в `sys.path`, обычный запуск `python test_sentinel_suite.py` работает (F-008 закрыт).
3. **Версия при ошибке проверки обновлений.** `handle_check_updates` брал `getattr(UPDATER, "current_version", "3.3.4")`, но такого атрибута нет, поэтому при сбое сети UI показывал 3.3.4. Теперь берётся `version.__version__`.
4. **Молчаливые ошибки.** Реальная картина: в `core` 27 пустых `pass`/`suppress` (почти все best-effort), во фронте и в `MainForm.cs` дефектными были сетевые обработчики полки/раздач/настроек и возврат звука после блэкаута. Исправлены с логированием (`console.error`, `desktop_errors.log`). Dispose/Unregister оставлены best-effort осознанно.
5. **Терминология.** «Раздачи» относятся только к вкладке бесплатных игр; для Twitch Drops используются «дропы / кампании».
6. **Вёрстка.** `.engraved-header .tag` не переносится; шапка планировщика Раздач переносит кнопки на 1280×720.

## Второй круг аудита (2026-11-01)

- **Изоляция тестов.** `test_sentinel_suite.py` строит песочницу во временной папке (код + снапшот данных без cookies/browser, без `node_modules`), запускает свой сервис на свободном порту (`SENTINEL_SERVICE_PORT`) в режиме `SENTINEL_TEST_MODE=1` (без движка Twitch и fetcher кампаний) и в конце сверяет sha256 боевых файлов. Полный прогон 36/36 при пробнике на 28492: 0 соединений; прогон проходит и при работающей программе. Остаточный риск: гейт `/api/clipboard/copy` пишет в буфер обмена Windows.
- **HTTP 429 от API кампаний.** `campaigns_fetcher.py`: при ошибке `_last_fetch_time` не менялся, поэтому каждый вызов бил в API снова; на старте всегда был принудительный запрос. Теперь: `Retry-After`, экспоненциальный backoff 60 → 1800 с с джиттером (блок действует и для `force`), возраст кэша берётся из mtime файла, старт без запроса при кэше младше 15 минут. Частота запросов нигде не увеличена.
- **Зависшие Node-процессы раздач.** Потолок 30 минут стоял после чтения stdout до EOF и не срабатывал на зависшем процессе; теперь он охватывает чтение. Шаги `npm install` / `patchright install` ограничены 15 минутами с `taskkill /T`. Остановка и перезапуск сервиса через API теперь гасят дерево Node.
- **Локализация консоли.** Сообщения ядра идут через `translate.py` (секция `sentinel`) и `lang/Русский.json`; язык движка берётся из `config.json` ключ `language`, по умолчанию «Русский». Исправлено `goes_offline`, который говорил «онлайн». Сообщения `GameScanner` остались английскими.
- **Выдуманная телеметрия** («+18Ч», «ТИК: 12С», «200 OK • DIRECT 18ms») убрана из дашборда.
- **Контраст.** `--text-muted` и `--text-engraved` доведены до AA в темах titanium, copper и light (luna-mint 4.3 и cyberpunk 4.4 на грани).
